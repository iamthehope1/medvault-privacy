
# MedVault Support

Thank you for using **MedVault**.

MedVault is a secure, offline-first clinical reference application built for healthcare professionals, residents, and medical students.

## Features

- Private clinical notes
- Specialty organization
- OCR document scanning
- Drug dosage references
- Medical knowledge vault
- Biometric security
- Local-first data storage

## Troubleshooting

### Face ID / Touch ID not working
Verify biometric authentication is enabled on your device.

### OCR scan issues
Ensure camera permission has been granted within iOS Settings.

### Import problems
Verify the imported file format is supported.

### Performance or bug reports
Please include:
- device model
- iOS version
- brief description of the issue
